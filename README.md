# Ay Peyzaj ve Çiçekçilik — aypeyzaj.com

Bartın'daki Ay Peyzaj ve Çiçekçilik firmasının web sitesi.

- Proje dokümanları: [`docs/`](docs/) (00–07). Tek doğru kaynak bunlardır.
- Teknoloji: Astro + içerik koleksiyonları, Cloudflare'de yayın. `main` dalı canlı sitedir.
- Güncelleme kuralları: [`docs/06-guncelleme-proseduru.md`](docs/06-guncelleme-proseduru.md)
- Cloudflare Pages ayarları: framework Astro, build komutu `npm run build`, çıktı klasörü `dist`. Node sürümü `.nvmrc` dosyasından okunur (22).
